3. Attested Queries, No-Omission Proofs, Audit Logs, & Recursive Aggregation

To prove that no record in a training set or log matches a forbidden pattern, verifying per-record parse/complement certificates is not enough: the verifier must also know that the server or trainer did not omit any record from the scan.

3.1 Dense Positional Non-Omission: Merkle Mountain Ranges (MMR.lean & dregg-query/src/mmr.rs)

In MMR.lean (commits ffd97ecf3 and 27259d03e, 2026-06-11; hardened in ed616d24c and ee18461c1, 2026-08-01), an append-only log $L : \text{List } \mathbb{Z}$ is decomposed into a canonical forest of complete binary peaks peaksOf L : List (MTree ℤ) with strictly decreasing heights (Mountains), whose root is bagged right-to-left via mroot hash L:

lean
theorem forestLeaves_peaksOf (L : List ℤ) : forestLeaves (peaksOf L) = L

theorem peaksOf_mountains (L : List ℤ) : Mountains (peaksOf L)

theorem mroot_binds_or_collides (hash : List ℤ → ℤ) {L₁ L₂ : List ℤ}
    (h : mroot hash L₁ = mroot hash L₂) :
    L₁ = L₂ ∨ SpongeColl hash (mrootFind hash L₁ L₂)

For any dense positional range $[lo, hi]$, RVerifies L lo hi vals checks that vals has exact length rangeCount L.length lo hi and every element vals[j] opens at position lo + j in L. Ember proves in MMR.lean that RVerifies is both sound and complete (rverifies_iff_exact), and therefore a server cannot omit any position:

lean
def RVerifies (L : List ℤ) (lo hi : ℕ) (vals : List ℤ) : Prop :=
  vals.length = rangeCount L.length lo hi ∧
    ∀ j v, vals[j]? = some v → Opens L (lo + j) v

theorem range_complete {L : List ℤ} {lo hi : ℕ} {vals : List ℤ}
    (hv : RVerifies L lo hi vals) :
    ∀ i, lo ≤ i → i ≤ hi → i < L.length →
      ∃ v, vals[i - lo]? = some v ∧ Opens L i v

theorem rverifies_iff_exact {L : List ℤ} {lo hi : ℕ} {vals : List ℤ} :
    RVerifies L lo hi vals ↔ vals = mrange L lo hi

theorem server_cannot_omit_position (hash : List ℤ → ℤ)
    {L L' : List ℤ}
    (hroot : mroot hash L' = mroot hash L)
    (hno : ¬ MRootColl hash L' L)
    {lo hi : ℕ} {vals : List ℤ}
    (hv : RVerifies L' lo hi vals) :
    vals = mrange L lo hi ∧
      ∀ i, lo ≤ i → i ≤ hi → i < L.length →
        ∃ v, vals[i - lo]? = some v ∧ Opens L i v

3.2 Key-Range Non-Omission & Gap Exclusion (HistoryIndex.lean, AttestedQuery.lean, dregg-query)

When querying by key rather than dense position (e.g., (subject, height, seq) in HistoryIndex.lean), positions are sparse, so a contiguous slice of results could still hide a matching key unless boundary gaps are proven empty. In HistoryIndex.lean and AttestedQuery.lean:

  • ReceiptKey := ℤ ×ₗ (ℤ ×ₗ ℤ) and ReceiptIndex := List (ReceiptKey × ℤ), committed via iroot hash idx.
  • inductive Gap (κ : Type u) witnesses an open interval (a, b) of adjacent keys in a sorted list l containing no keys between a and b:
lean
  inductive Gap (κ : Type u)
    | empty
    | below (b : κ)
    | inner (a b : κ)
    | above (a : κ)

  theorem Gap.excludes {l : List κ} {g : Gap κ} {k : κ}
      (hs : Sorted l) (hv : g.Valid l) (hc : g.covers k) : k ∉ l
  • An Answer κ ν carries items : List (κ × ν) plus boundary gap witnesses leftGap : Gap κ and rightGap : Gap κ. Verifies h lo hi ans checks that items is a contiguous sublist (IsInfix) of the sorted index h and that leftGap / rightGap bridge lo to items.head and items.last to hi (or cover [lo, hi] when items = []).
  • Key-Range Non-Omission Theorem (AttestedQuery.lean):
lean
  def AnswerComplete (h : List (κ × ν)) (lo hi : κ) (ans : Answer κ ν) : Prop :=
    ∀ e ∈ h, inRange lo hi e.1 → e ∈ ans.items

  theorem answer_complete {h : List (κ × ν)} {lo hi : κ} {ans : Answer κ ν}
      (hs : SortedKeys h) (hv : Verifies h lo hi ans) :
      AnswerComplete h lo hi ans

  theorem server_cannot_omit (hash : List ℤ → ℤ) (hCR : Poseidon2SpongeCR hash)
      {idx idx' : ReceiptIndex}
      (hs : SortedKeys idx)
      (hroot : iroot hash idx' = iroot hash idx)
      {lo hi : ReceiptKey} {ans : Answer ReceiptKey ℤ}
      (hv : Verifies idx' lo hi ans) :
      AnswerComplete idx lo hi ans ∧
        (∀ e ∈ ans.items, e ∈ idx ∧ inRange lo hi e.1)

Notice the empty-answer case (ans.items = []): Verifies requires ans.leftGap.Valid keys ∧ ans.leftGap.covers lo ∧ ans.leftGap.covers hi. By convexity of Gap.covers and Gap.excludes, every key $k \in [lo, hi]$ is proven absent ($k \notin \text{keys}$) from the committed index!

3.3 dregg-query Attested Slices, Paged Windows, CALM Classification, & Zero-Count Aggregation

In dregg-query/src/:

  • attested.rs:
  • RangeCertificate wraps RangeOpening, lo, and hi.
  • AttestedSlice pairs receipts: Vec<TurnReceipt> with cert: RangeCertificate. AttestedSlice::verify(&self, expected_root: &[u8; 32]) checks self.receipts.len() == self.cert.opening.values.len(), verifies each receipt.receipt_hash().0 == leaf, and runs verify_range::<Blake3Mmr>(expected_root, self.cert.lo, self.cert.hi, &self.cert.opening).
  • Coverage (Coverage::WholeLog vs Coverage::Range { lo, hi }) and AttestedAnswer: AttestedAnswer::verify(&self, expected_root: &[u8; 32]) enforces that Coverage::WholeLog covers lo == 0 and (len == 0) || (hi + 1 >= len) (refusing PartialCoverageForWholeLog if truncated), extracts the EDB FactBase from the verified receipts, re-evaluates eval(&base, &self.query), and checks recomputed == self.rows (AnswerMismatch if tampered).
  • windows.rs:
  • verify_windows(expected_root: &[u8; 32], windows: &[IndexRangeResponse]) -> Result<Vec<TurnReceipt>, WindowVerifyError> stitches paged range responses into a single fail-closed whole-log read: it checks that every window's node attestation is signed by the same node_pubkey and binds expected_root, checks lo == expected_lo (rejecting overlaps or gaps with WindowGapOrOverlap), guards against hi == usize::MAX arithmetic overflow, verifies each slice.verify(expected_root), and requires expected_lo == len at the end (LogTailTruncated if the tail is omitted).
  • classify.rs & query.rs:
  • classify(q: &Query) -> CoordinationClass implements the CALM theorem classifier: positive conjunctive queries are CoordinationClass::Monotone (valid on prefixes), whereas queries using not_atom (negation) or aggregate (AggOp::{Count, Sum, Min, Max}) are CoordinationClass::FinalizedDependent and require a Coverage::WholeLog no-omission proof.
  • Crucially, in aggregate(), when group_by is empty (a global aggregate) and AggOp::Count is evaluated over an empty match set (rows.is_empty()), it emits a single row [Value::Int(0)]—a cryptographically attested count = 0 absence verdict over the whole log!

3.4 Audit Log Proofs (audit/src/log.rs, audit/src/proofs.rs, audit/src/budget.rs)

In dregg-audit, AuditLog<H: TreeHash> maintains a 4-ary append-only Merkle tree (ARITY = 4) over AuditEntry records (generic over PoseidonTreeHash and Blake3TreeHash) with four verifiable proof types in proofs.rs and budget.rs:

  1. CountProof: Proves the exact total entry count (count: u64) under root: [u8; 32] in $O(\log_4 N)$ size via the rightmost spine right_spine: Vec<SpineStep> (CountProof::verify checks that every step uses the last populated child slot and reconstructs root).
  2. RangeProof: Proves that a contiguous slice of entries [start, end) is complete and unmodified under root (RangeProof::verify checks entries.len() == end - start and verifies boundary + sample inclusion proofs).
  3. ConsistencyProof: Proves that old_root (at old_size) is a prefix of new_root (at new_size).
  4. BudgetProof: Combines a RangeProof over [0, log_size) with CountProof (completeness_proof) to prove that the sum of resource usage matching a BudgetDimension (ActionCount or ParamSum) across the entire log is claimed_total <= limit—and when limit = 0, proves zero occurrences (claimed_total == 0) across the entire log!

5. Synthesis: End-to-End Protocol for Proving the Absence of Information from a Training Set / Workload Corpus

Step-by-Step Verification Chain & Governing Theorems

Step 1: Dual-Anchored Dataset Commitment (ContentCommit, Blake3Mmr, ReceiptIndex)

  • Each training document or tokenized batch $d_i$ ($i \in \{0, \dots, N-1\}$) is committed via the 8-lane Poseidon2 sponge content_commitment(&d_i) -> [BabyBear; 8] ($\sim 123.63$-bit collision resistance, avoiding the 1-felt wound catalogued in project-felt-width-repair-campaign.md).
  • Each record's receipt—binding c_i : ContentCommit and its policy-compliance verdict tag—is appended to:
  • The dense positional Merkle Mountain Range Blake3Mmr with root R_D = mroot hash L, and/or
  • The sorted key-indexed ReceiptIndex (ReceiptKey = (subject, height, seq)) with root I_D = iroot hash idx and the 4-ary AuditLog<PoseidonTreeHash>.
  • Governing Lean Theorem: mroot_binds_or_collides ensures that under Poseidon2SpongeCR hash (or BLAKE3 collision resistance), the committed sequence $L = [r_0, \dots, r_{N-1}]$ is uniquely pinned by R_D.

Step 2: Verified Complement Compilation (Pattern::Not, Re::not(), PredRE.neg)

  • The auditor specifies the forbidden information as a regular expression or predicate pattern $P_{\text{forbid}}$ (or a union of forbidden patterns $P_1 \cup P_2 \cup \dots \cup P_k$, e.g., * ⬝ canary_bytes ⬝ *).
  • Using Pattern::Not(Box::new(P_forbid)).compile(), dregg-dfa lowers $\neg P_{\text{forbid}}$ to Re::not() and compiles it via lazy Brzozowski byte-class derivatives (Re::compile()) into a flat transition table Dfa { num_states, transitions, start, accepting }.
  • Governing Lean Theorems:

Executive Summary: Why Proving Absence Requires Five Interlocking Primitives

Proving a positive fact about a dataset or log—such as "document $d$ is in training corpus $C$"—requires only a single Merkle inclusion path. By contrast, proving a negative (absence) property—such as "no training example in corpus $C$ contains PII pattern $P$, copyrighted canary $K$, benchmark test question $Q$, or template-breaking injection payload $I$, without revealing the corpus $C$"—is a universal quantification ($\forall i \in [0, |C|), \text{record}_i \notin \mathcal{L}(P)$) over private, structured data.

An adversarial prover attempting to forge an absence proof has five distinct attack surfaces:

  1. Language-Complement Evasion: Standard regular expression engines (Thompson $\varepsilon$-NFAs) cannot express complement ($\neg P$) or intersection ($P_1 \cap P_2$) without eager powerset determinization at every negation node.
  2. Structural / Framing Smuggling: A forbidden string or control token split across JSON fields or template holes, or embedded in malformed syntax, can fool a flat scanner that lacks a context-free grammar (CFG) parse proof.
  3. Cross-Leg Splicing / Narrow Commitment Collisions: Proving authenticity on document $A$ while running the absence matcher on a benign document $B$, or exploiting a narrow 1-felt ($\sim 31$-bit) commitment waist via birthday or linear-combination collisions.
  4. Selective Omission / Log Slicing: Returning an attested query over 99.9% of the training corpus while silently dropping the positions or index keys that contain the forbidden information, or truncating the prefix/suffix of the dataset log.
  5. Linear Verification Blowup: Shipping millions of per-record STARK proofs and Merkle openings that no light client or auditor can verify in constant time.

B. Symbolic Byte-Class Derivative Engine (dfa/src/derivative.rs)

In derivative.rs, character classes over u8 are represented as canonical, sorted, non-overlapping inclusive intervals ByteClass with exact Boolean operations (union, intersect, complement), and extended regular expressions are represented by Re:

rust
#[derive(Clone, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub struct ByteClass {
    /// Sorted, non-overlapping, adjacent-merged `(low, high)` inclusive ranges.
    ranges: Vec<(u8, u8)>,
}

#[derive(Clone, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
pub enum Re {
    /// `∅` — matches nothing.
    Empty,
    /// `ε` — matches only the empty input `""`.
    Epsilon,
    /// Single byte in `ByteClass` (always non-empty; empty class normalizes to `Empty`).
    Sym(ByteClass),
    /// Concatenation `R · S`.
    Cat(Box<Re>, Box<Re>),
    /// Union / alternation `R | S`.
    Alt(Box<Re>, Box<Re>),
    /// Intersection `R & S` — derived lazily: `δ_b(R & S) = δ_b(R) & δ_b(S)`.
    Inter(Box<Re>, Box<Re>),
    /// Complement `~R` — derived natively: `δ_b(~R) = ~δ_b(R)`, `ν(~R) = !ν(R)`.
    Neg(Box<Re>),
    /// Kleene star `R*` (zero or more repetitions).
    Star(Box<Re>),
}

To guarantee that Brzozowski determinization terminates in a small number of states, Re enforces ACI (Associativity, Commutativity, Idempotence) canonicalization inside its smart constructors (Re::then, Re::or, Re::and, Re::not, Re::star):

  • Re::or and Re::and sort operands via derived Ord (let (l, r) = if l <= r { (l, r) } else { (r, l) }), flatten right-associatively, deduplicate R | R = R and R & R = R, and short-circuit on Empty and Re::any_bytes() ($\Sigma^* = \neg\emptyset$).
  • Re::not(r: Re) -> Self eliminates double negation (Re::Neg(inner) => *inner).
  • Nullability Re::nullable(&self) -> bool and the Brzozowski derivative Re::derive(&self, b: u8) -> Re are defined directly on the normalized AST:
rust
pub fn nullable(&self) -> bool {
    match self {
        Re::Empty | Re::Sym(_) => false,
        Re::Epsilon | Re::Star(_) => true,
        Re::Cat(l, r) | Re::Inter(l, r) => l.nullable() && r.nullable(),
        Re::Alt(l, r) => l.nullable() || r.nullable(),
        Re::Neg(r) => !r.nullable(),
    }
}

pub fn derive(&self, b: u8) -> Re {
    match self {
        Re::Empty | Re::Epsilon => Re::Empty,
        Re::Sym(cls) => {
            if cls.contains(b) { Re::Epsilon } else { Re::Empty }
        }
        Re::Cat(l, r) => {
            let dl_r = l.derive(b).then((**r).clone());
            if l.nullable() { dl_r.or(r.derive(b)) } else { dl_r }
        }
        Re::Alt(l, r) => l.derive(b).or(r.derive(b)),
        Re::Inter(l, r) => l.derive(b).and(r.derive(b)),
        Re::Neg(r) => r.derive(b).not(),
        Re::Star(r) => r.derive(b).then(self.clone()),
    }
}

Instead of calling derive(b) 256 times per reachable state, Re::derivative_classes(&self) -> Vec<(u8, u8)> collects all interval cut-points from Sym(cls) leaves (collect_cuts) to partition $[0, 255]$ into equivalence classes [lo, hi] on which every leaf predicate has constant truth value. Then Re::compile(&self) -> Dfa explores only reachable derivative states, evaluating cur_re.derive(lo) once per equivalence class and fanning next_id across transitions[base + b] for b in lo..=hi. Conversely, Re::from_dfa(dfa: &Dfa) -> Re implements state elimination so any compiled Dfa can be lifted back into Re and complemented via .not().

A. PredRE, null, der, derives, and Matches (Core.lean)

lean
inductive PredRE where
  | ε
  | sym   (φ : Pred)
  | alt   (l r : PredRE)
  | inter (l r : PredRE)
  | cat   (l r : PredRE)
  | star  (r : PredRE)
  | neg   (r : PredRE)
  deriving Repr, DecidableEq

@[simp]
def leaf (φ : Pred) (a : Value) : Bool :=
  φ.eval (symbolOld a) a

@[simp]
def null : PredRE → Bool
  | .ε         => true
  | .sym _     => false
  | .alt l r   => null l || null r
  | .inter l r => null l && null r
  | .cat l r   => null l && null r
  | .star _    => true
  | .neg r     => !(null r)

@[simp]
def der (a : Value) : PredRE → PredRE
  | .ε         => .sym .ff
  | .sym φ     => if leaf φ a then .ε else .sym .ff
  | .alt l r   => .alt (der a l) (der a r)
  | .inter l r => .inter (der a l) (der a r)
  | .neg r     => .neg (der a r)
  | .cat l r   => if null l
                  then .alt (.cat (der a l) r) (der a r)
                  else .cat (der a l) r
  | .star r    => .cat (der a r) (.star r)

@[simp]
def derives : List Value → PredRE → Bool
  | [],      R => null R
  | a :: as, R => derives as (der a R)

Note how leaf supports both stateless single-frame evaluation (symbolOld a = emptyFrame when unassigned) and stateful two-frame transition pairs crafted via transitionSymbol (old : Value) : Value → Value (Core.lean).

The declarative semantics Matches : List Value → PredRE → Prop is defined by well-founded recursion on starMetric R = toLex (starHeight R, size R):

lean
def Matches (w : List Value) (R : PredRE) : Prop :=
  match R with
  | .ε         => w = []
  | .sym φ     => ∃ a : Value, w = [a] ∧ leaf φ a = true
  | .alt l r   => Matches w l ∨ Matches w r
  | .inter l r => Matches w l ∧ Matches w r
  | .cat l r   => ∃ w₁ w₂ : List Value, w₁ ++ w₂ = w ∧ Matches w₁ l ∧ Matches w₂ r
  | .neg r     => ¬ Matches w r
  | .star r    => ∃ n : Nat, Matches (w := w) (repeatCat r n)
termination_by (starMetric R, w.length)

1.2 The Machine-Checked Commit-Then-Audit Theorem (Selvage/AuditSampling.lean)

As documented in docs/SELVAGE.md and notes/audit-theorem-statement.md, commercial verifiable-inference providers (e.g., Attestable Audits, arXiv 2506.23706) argue commit-then-audit detection with a one-line union bound $1 - (1 - p)^k$ that silently treats the commitment as perfectly binding ($\varepsilon_{\text{bind}} = 0$), the proof checker as infallible ($\varepsilon_{\text{chk}} = 0$), the random audit coin as unbiasable ($\varepsilon_{\text{beacon}} = 0$), and the adversary's corruption schedule as non-adaptive (i.i.d.).

In Selvage/AuditSampling.lean, Ember formalized and proved the first machine-checked commit-then-audit theorem in Lean 4 with all three cryptographic error legs and full adaptive stopping-time schedules.

A. Parameter Bundle & Effective Per-Turn Detection Rate $q$

From Selvage/AuditSampling.lean:

lean
structure AuditParams where
  /-- Nominal audit firing probability `p ∈ [0,1]`. -/
  p : ℝ
  /-- Proof-system soundness error `ε_chk ∈ [0,1]`: bound on `Pr[accept | fired, corrupt]`. -/
  εchk : ℝ
  /-- Commitment-binding break probability `ε_bind ≥ 0` per round. -/
  εbind : ℝ
  /-- Beacon bias `ε_beacon ≥ 0`: how much the adversary can depress `Pr[fires]`. -/
  εbeacon : ℝ
  hp_nonneg : 0 ≤ p
  hp_le_one : p ≤ 1
  hchk_nonneg : 0 ≤ εchk
  hchk_le_one : εchk ≤ 1
  hbind_nonneg : 0 ≤ εbind
  hbeacon_nonneg : 0 ≤ εbeacon

namespace AuditParams

/-- **The effective per-corrupt-turn detection rate**:
`q = p · (1 − ε_chk) − ε_bind − ε_beacon`. -/
def q (A : AuditParams) : ℝ :=
  A.p * (1 - A.εchk) - A.εbind - A.εbeacon

B. Predictable ($\mathcal{F}_{t-1}$-Measurable) Adaptive Corruption & The Three Cryptographic Legs

Crucially, predictability (the commit-before-coin ordering that prevents an adversary from peeking at the audit coin $\omega_t$ before deciding whether turn $t$ is corrupt) is enforced by the Lean type signature of Round.corrupt, which takes only the prior history List Ω and not the current coin ω : Ω (Selvage/AuditSampling.lean):

lean
structure Round (Ω : Type) where
  /-- Whether the prover corrupts this round, as a function of the **prior**
  history `h : List Ω` ONLY. Does not take `ω : Ω` — predictability is a type. -/
  corrupt : List Ω → Bool
  /-- Whether the audit beacon fires on coin `ω` after history `h`. -/
  fires : List Ω → Ω → Bool
  /-- Whether the audit raises an alarm (`alarm_t = 1`). -/
  alarms : List Ω → Ω → Bool
  /-- Checker soundness-failure event: the checker was run and accepted a
  corrupt claim. -/
  chkErr : List Ω → Ω → Bool
  /-- Checker abort / timeout / malformed-proof event (`V = ⊥`). Separated from
  `chkErr` so the fail-open vs fail-closed distinction is expressible. -/
  chkAbort : List Ω → Ω → Bool
  /-- Commitment-binding break event: the prover produced a second valid opening
  for the committed digest `c_t`. -/
  bindBreak : List Ω → Ω → Bool

The three cryptographic assumptions and the miss-decomposition hypothesis are defined over Round Ω (Selvage/AuditSampling.lean):

lean
/-- **Leg 3 (beacon)**: `Pr_ω[fires h ω] ≥ p − ε_beacon` at every history `h`. -/
def BeaconLeg (A : AuditParams) (R : Round Ω) : Prop :=
  ∀ h : List Ω, A.p - A.εbeacon ≤ uniformProb Ω (fun ω => R.fires h ω)

/-- **Leg 1 (checker soundness, conditional on firing)**: on any corrupt round,
`Pr_ω[fires ∧ chkErr] ≤ Pr_ω[fires] · ε_chk`. Written in product form to avoid
dividing by `Pr[fires]` (which may be `0` when `p ≤ ε_beacon`). -/
def ChkLeg (A : AuditParams) (R : Round Ω) : Prop :=
  ∀ h : List Ω, R.corrupt h = true →
    uniformProb Ω (fun ω => R.fires h ω ∧ R.chkErr h ω) ≤
      uniformProb Ω (fun ω => R.fires h ω) * A.εchk

/-- **Leg 2 (commitment binding)**: `Pr_ω[bindBreak h ω] ≤ ε_bind` at every history. -/
def BindLeg (A : AuditParams) (R : Round Ω) : Prop :=
  ∀ h : List Ω, uniformProb Ω (fun ω => R.bindBreak h ω) ≤ A.εbind

/-- **Miss decomposition**: if the round is corrupt, the audit fires, and no
alarm is raised, then either the checker failed soundness (`chkErr`) or the
commitment was double-opened (`bindBreak`). -/
def MissDecomp (R : Round Ω) : Prop :=
  ∀ (h : List Ω) (ω : Ω),
    R.corrupt h = true → R.fires h ω = true → R.alarms h ω = false →
      R.chkErr h ω = true ∨ R.bindBreak h ω = true

/-- All four single-round hypotheses bundled. -/
structure DetectionLegs (A : AuditParams) (R : Round Ω) : Prop where
  beacon : R.BeaconLeg A
  chk    : R.ChkLeg A
  bind   : R.BindLeg A
  miss   : R.MissDecomp

C. Fail-Closed vs. Fail-Open Refutation (FailOpenRefutation)

If an implementation treats checker timeout or malformed proof (chkAbort) as a non-alarm ("fail-open", e.g., logging a warning and continuing), an adversary can deterministically abort whenever audited (chkAbort = true), achieving chkErr = false, bindBreak = false, and alarms = false. D. Single-Round Detection Lemma (Round.detect)

How $\varepsilon_{\text{chk}}$, $\varepsilon_{\text{bind}}$, and $\varepsilon_{\text{beacon}}$ compose: on any corrupt turn $h$, the event fires splits into alarms or a miss (fires ∧ ¬alarms). By MissDecomp, every miss implies fires ∧ chkErr or bindBreak. By finite-type cardinality decomposition (card_split_imp), $\Pr[\text{alarms}] \ge \Pr[\text{fires}] - \Pr[\text{fires} \wedge \text{chkErr}] - \Pr[\text{bindBreak}] \ge \Pr[\text{fires}](1 - \varepsilon_{\text{chk}}) - \varepsilon_{\text{bind}}$. Since $1 - \varepsilon_{\text{chk}} \ge 0$ (AuditParams.hchk_le_one), applying $\Pr[\text{fires}] \ge p - \varepsilon_{\text{beacon}}$ yields $\Pr[\text{alarms}] \ge (p - \varepsilon_{\text{beacon}})(1 - \varepsilon_{\text{chk}}) - \varepsilon_{\text{bind}} \ge p(1 - \varepsilon_{\text{chk}}) - \varepsilon_{\text{bind}} - \varepsilon_{\text{beacon}} = q$ (Selvage/AuditSampling.lean):

lean
theorem detect [Nonempty Ω] (hL : DetectionLegs A R) {h : List Ω}
    (hc : R.corrupt h = true) :
    A.q ≤ uniformProb Ω (fun ω => R.alarms h ω)

E. Supermartingale $M_t$, Optional Stopping Corrupt-Turn Bound $\mathbb{E}[C_\tau] \le 1/q$, and Leakage Bound $\mathbb{E}[\Lambda] \le b/q$

Rather than importing measure-theoretic probability spaces, Ember defined exact finite-horizon backward induction expOver over the $\sigma$-algebra of coin prefixes List Ω and proved Doob's optional stopping inequality le_of_step in 12 lines of induction (Selvage/AuditSampling.lean). Defining the stopped process at the first alarm $\tau = \inf\{t : \text{alarm}_t = 1\}$ and the potential $M_t = q \cdot C_{t \wedge \tau} - \mathbf{1}_{\{\tau \le t\}}$ (Round.mart), Ember proved (Selvage/AuditSampling.lean):

lean
/-- Whether the process has stopped (an alarm has fired at or before this history). -/
def stopped (R : Round Ω) : List Ω → Bool
  | [] => false
  | ω :: h => R.stopped h || R.alarms h ω

/-- Pre-alarm corrupt-round counter `C_{t ∧ τ}`: increments on round `h → ω :: h`
iff the process was not yet stopped at `h` AND the prover corrupted round `h`. -/
def count (R : Round Ω) : List Ω → ℕ
  | [] => 0
  | _ :: h =>
      if R.stopped h then R.count h
      else if R.corrupt h then R.count h + 1 else R.count h

/-- The supermartingale potential `M(h) = q · C(h) − 1_{stopped(h)}`. -/
noncomputable def mart (R : Round Ω) (q : ℝ) (h : List Ω) : ℝ :=
  q * (R.count h : ℝ) - (if R.stopped h = true then (1 : ℝ) else 0)

/-- **THE SUPERMARTINGALE STEP.** If every unstopped corrupt round alarms with
probability at least `q`, then `(1/|Ω|) ∑_ω M(ω :: h) ≤ M(h)` at **every** history `h`. -/
theorem mart_step [Nonempty Ω] {R : Round Ω} {q : ℝ}
    (hdet : ∀ h : List Ω, R.stopped h = false → R.corrupt h = true →
      q ≤ uniformProb Ω (fun ω => R.alarms h ω))
    (h : List Ω) :
    (∑ ω : Ω, R.mart q (ω :: h)) / (Fintype.card Ω : ℝ) ≤ R.mart q h

/-- **THE SEQUENTIAL CORRUPT-TURN BOUND (optional stopping).**
For any horizon `n` and any adaptive corruption strategy, if `q > 0` and every
unstopped corrupt round alarms with probability `≥ q`, then
`E[C_{n ∧ τ}] ≤ 1 / q`. -/
theorem sequential_bound [Nonempty Ω] {R : Round Ω} {q : ℝ} (hq : 0 < q)
    (hdet : ∀ h : List Ω, R.stopped h = false → R.corrupt h = true →
      q ≤ uniformProb Ω (fun ω => R.alarms h ω))
    (n : ℕ) :
    expOver Ω n (fun h => (R.count h : ℝ)) [] ≤ 1 / q

/-- **THE LEAKAGE COROLLARY.** If each undetected corrupt turn leaks at most
`b ≥ 0` bits, expected total leakage before the first alarm is at most `b / q`
bits — independent of the horizon `n` and of the adversary's adaptive schedule. -/
theorem leakage_bound [Nonempty Ω] {R : Round Ω} {q b : ℝ} (hq : 0 < q)
    (hb : 0 ≤ b)
    (hdet : ∀ h : List Ω, R.stopped h = false → R.corrupt h = true →
      q ≤ uniformProb Ω (fun ω => R.alarms h ω))
    (n : ℕ) :
    expOver Ω n (fun h => b * (R.count h : ℝ)) [] ≤ b / q

/-- **THE END-TO-END COMPOSED THEOREM.** Under the three cryptographic legs
(`BeaconLeg`, `ChkLeg`, `BindLeg`) and `MissDecomp`, if
`q = p(1 − ε_chk) − ε_bind − ε_beacon > 0`, expected undetected corrupt turns
over any horizon `n` and any adaptive strategy is at most `1 / q`. -/
theorem sequential_bound_of_legs [Nonempty Ω] {A : AuditParams} {R : Round Ω}
    (hL : DetectionLegs A R) (hq : 0 < A.q) (n : ℕ) :
    expOver Ω n (fun h => (R.count h : ℝ)) [] ≤ 1 / A.q

A. Two Soundness Bugs Discovered in Prior Art (ZK-DeepSeek & OP-10)

  1. Bug 1 — BF16 Score Ties Give ~23 Bits of Routing Freedom Per Token:
  2. OP-10 (arXiv 2606.05433 §4.4.3) claims top-$k$ ties are "rare with BF16", and ZK-DeepSeek (arXiv 2511.19902 §3.7) enforces only non-decreasing sorted order $L'[i-1] \le L'[i]$ via multiset permutation without proving permutation of indices.
  3. Ember proved this is mathematically backwards (notes/moe-router-binding.md:94-110, 419-462): BF16 has only 7 mantissa bits ($2^7 = 128$ binades), which is smaller than the number of experts ($E = 256$). Worse, DeepSeek-V3 uses a sigmoid router where top experts cluster near $1.0$: in $[0.9, 1.0)$, there are only 26 distinct BF16 values across 256 experts! By pigeonhole, ~10–15 experts tie near the top-$k$ boundary on every token, giving a malicious prover $\binom{12}{4} \approx 495$ choices per layer or ~23 bits of silent routing freedom per token to pick weaker or poisoned experts while satisfying ZK-DeepSeek's constraints.
  4. The Fix — Canonical Composite Key (C3): Shift each quantized score $v_i \in [0, 2^B)$ by $\lceil \log_2 n' \rceil$ bits and pack the inverted index $(n' - 1 - i)$ into the low bits so all keys are strictly distinct and ties break lowest-index-first (matching PyTorch torch.topk / vLLM moe_topk): $$\text{key}_i := v_i \cdot 2^{\lceil \log_2 n' \rceil} + (n' - 1 - i) + 1 \in [1, 2^{B + \lceil \log_2 n' \rceil}]$$
  5. Bug 2 — Monolithic Weight MLE Opening Restores Full 671B Dense Cost:
  6. ZK-DeepSeek reuses weight-matrix proofs across tokens without binding the expert index $\vec{e}$ to the router output (notes/moe-router-binding.md:107-110).
  7. Conversely, if a prover commits to a single monolithic layer tensor $\tilde{W}(\vec{e}, \vec{u}, \vec{v})$ and opens it at $\vec{e} = \text{bits}(\text{id}_j)$ via sumcheck/PCS, a multilinear PCS opening touches every coefficient of $\tilde{W}$ in $\Theta(E \cdot d \cdot f)$ time — completely erasing the 18.3× sparse MoE discount (notes/moe-router-binding.md:486-526).
  8. The Fix — Per-Expert Commitments ($R_{\ell,e}$): Commit each expert $e$ to its own root $R_{\ell,e}$ and open the tiny 257-element vector $R_\ell$ verifier-side in $O(E) = 257$ field ops.

B. Variant (b) Threshold Top-$k$ Argument & The 0.72% Trace Overhead

Instead of sorting all $n=256$ experts via a 1,920-cell Batcher bitonic network + 1,040 LogUp terms (Variant (a), which took ZK-DeepSeek 2,447 s for 24 tokens), Ember designed Variant (b) (notes/moe-router-binding.md:306-384): witness the binary selection mask $\sigma \in \{0,1\}^n$ and a single threshold $\tau \in \mathbb{F}$ satisfying:

  • (C1) $\sigma_i \cdot (1 - \sigma_i) = 0\quad \forall i \in [0, n)$
  • (C2) $\sum_{i=0}^{n-1} \sigma_i = k$
  • (C3) $\text{key}_i = v_i \cdot 2^{\lceil \log_2 n \rceil} + (n - 1 - i) + 1$
  • (C4) $\text{RangeCheck}(\Delta_i \in [0, 2^{B'})) \quad \text{where } \Delta_i = \sigma_i(\text{key}_i - \tau) + (1 - \sigma_i)(\tau - 1 - \text{key}_i)$
  • (C5) $\text{RangeCheck}(\tau \in [0, 2^{B'}))$ (mandatory wraparound-trap guard preventing $\tau = p - M$ from wrapping mod $p$).

5.2 TPU: CROSS INT8 Systolic MXU GEMMs, BAT $K=4$, & The Amdahl Hash-Bound Law

In docs/HARDWARE.md §2, docs/VERDICTS.md §4b, and docs/COST-MODEL.md, Ember evaluated Google TPU v6e (Trillium) INT8 Matrix Multiply Units (MXU) for ZK and vFHE:

  • CROSS (ePrint 2026/160, HPCA 2026): Maps modular NTT and polynomial arithmetic onto TPU v6e INT8 systolic arrays via Basis Aligned Transformation (BAT), achieving 1.43× faster NTT than WarpDrive on A100, 451× perf/W over OpenFHE, and ~10× over GZKP on V100.
  • Exact Transfer of BAT to 31-Bit BabyBear (breadstuffs/fhegg-fhe/src/bin/ntt_four_step_bench.rs):
  • BAT precomputes $a \cdot 2^{8i} \bmod q$ offline for a preknown twiddle $a$, turning a modular multiplication $a \cdot b \bmod q$ into a $K \times K$ unsigned byte-matrix product.
  • Because $4 \times 8 = 32 > 31$, 31-bit BabyBear uses $K = 4$ — the exact same $K=4$ matrix shape as CROSS with zero modification, running 3.05× faster than 3-limb Montgomery even on scalar hardware without an INT8 tensor unit!
  • Two Critical Caveats Established by Measurement (VERDICTS.md §4b):
  • Preknown Operand Requirement: BAT's $K \times K$ table requires one operand to be known offline (true for NTT twiddles, false for two-witness MLE sumcheck folds).
  • Amdahl Ceiling (1.26×) & Four-Step NTT Blowup: By instrumenting the deployed prover with exact operation counters (breadstuffs/circuit/tests/ir2_field_op_counts.rs, 2,245 lines), Ember proved that the prover is hash-bound by 5.0–7.2× (X ≤ 178 arithmetic ops/perm vs Y = 890 hash ops/perm), so LDE NTT is only 20.8% of prove time (capping any tensor-core LDE speedup at 1.26×), and four-step matrix NTT suffers a $\sqrt{N}/\log N$ twiddle-multiply blowup (3,277× more multiplies at $N = 2^{20}$).
